# PHP Introducción  
práctica y aprendizaje de fundamentos de PHP. Este proyecto contiene ejemplos organizados por temas que cubren desde sintaxis básica hasta manejo de datos estructurados, con el objetivo de construir una base sólida en desarrollo backend.
##  Contenidos  
- Variables
- Tipos de datos
- Condicionales
- Bucles
- Arrays
- Funciones
- Manejo de JSON
- Includes
Estructuras básicas de backend

## Objetivo del repositorio
Aprender sintaxis de PHP
Comprender estructuras de datos
Manejo de JSON
Lógica backend
Preparación para APIs y desarrollo web
Buenas prácticas
Organización de código
Fundamentos sólidos
Base para backend profesional
